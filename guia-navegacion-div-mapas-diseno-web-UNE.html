Barras de Navegacion

Estructura, propiedades y caracteristicas

La barra de navegacion es el sistema de orientacion de un sitio web: guia al usuario entre las distintas secciones y comunica visualmente la estructura del contenido. Es uno de los elementos de interfaz mas importantes desde la perspectiva del diseno y la experiencia de usuario.

Estructura basica de una barra de navegacion

Una barra de navegacion se construye tipicamente combinando tres elementos: la etiqueta semantica <nav> como contenedor, una lista no ordenada <ul> con sus elementos <li>, y enlaces <a> dentro de cada elemento de lista.

<nav> — contenedor semantico de navegacion
↓ contiene
<ul> — lista de enlaces
↓ contiene
<li> — cada elemento de la lista
↓ contiene
<a> — el enlace navegable
navbar-estructura.html 
<nav>
  <ul>
    <li><a href="#inicio">Inicio</a></li>
    <li><a href="#nosotros">Nosotros</a></li>
    <li><a href="#servicios">Servicios</a></li>
    <li><a href="#contacto">Contacto</a></li>
  </ul>
</nav>
ⓘ
El uso de <ul> y <li> no es casual: semanticamente, un menu es una lista de opciones. Esta estructura mejora la accesibilidad y permite que lectores de pantalla anuncien la cantidad de elementos de navegacion disponibles.

Propiedades CSS para dar forma a la barra

Sin estilos, la lista se muestra en vertical y con vinetas. Las siguientes propiedades CSS transforman esa lista en una barra de navegacion profesional.

</style>

Caracteristicas y variantes de navegacion

Segun el diseno del sitio, la barra de navegacion puede presentar distintas orientaciones y comportamientos.

Navegacion horizontal

La mas comun en encabezados de sitios. Se logra con display: flex. Ideal para menus de pocas opciones ubicados en la parte superior.

Navegacion vertical

Los enlaces se apilan uno debajo de otro (sin display: flex o con flex-direction: column). Comun en barras laterales o menus de paneles.

Navegacion fija (sticky)

Con position: sticky o fixed, la barra permanece visible al desplazarse. Mejora la orientacion en paginas largas.

Enlace activo (activo)

Se resalta la seccion actual con una clase CSS (ej. .activo) para indicar al usuario donde se encuentra dentro del sitio.

Estructura con la Etiqueta DIV

Organizacion y maquetacion del contenido en contenedores

La etiqueta <div> es un contenedor generico de bloque que agrupa elementos para organizarlos, posicionarlos y estilizarlos como una unidad. Es la herramienta fundamental para maquetar la estructura visual de una pagina web.

Que es la etiqueta div y para que sirve

Un <div> (division) no aporta significado semantico por si mismo: su funcion es agrupar contenido para aplicarle estilos o posicionarlo en conjunto. Se comporta como un bloque, es decir, ocupa todo el ancho disponible y provoca un salto de linea antes y despues.

div-basico.html 
<div class="tarjeta">
  <h2>Titulo de la seccion</h2>
  <p>Contenido agrupado dentro del contenedor.</p>
</div>
ⓘ
Los atributos class e id son la clave para trabajar con contenedores: permiten "nombrar" un <div> para aplicarle estilos CSS especificos. class puede repetirse en varios elementos; id debe ser unico en toda la pagina.

Div frente a etiquetas semanticas

HTML5 introdujo etiquetas semanticas que cumplen la funcion de un <div> pero con significado. Conviene conocer ambas y elegir la mas adecuada.

EtiquetaSignificadoCuando usarla
<div>Contenedor generico sin significadoAgrupaciones puramente visuales o de maquetacion
<header>EncabezadoParte superior con logo y navegacion
<main>Contenido principalCuerpo central de la pagina (unico)
<section>Seccion tematicaBloques de contenido diferenciados
<footer>Pie de paginaInformacion final, creditos, contacto
✓
Buena practica: usa etiquetas semanticas cuando el bloque tenga un rol claro (header, footer, section) y reserva <div> para agrupaciones de maquetacion sin significado propio, como una fila de tarjetas o una columna.

Maquetacion con div: el modelo de caja

Cada <div> se comporta como una caja rectangular. El modelo de caja (box model) define cuatro capas que controlan su tamano y espaciado.

Propiedades del modelo de caja

  • width / height: dimensiones del contenido
  • padding: espacio interno (entre borde y contenido)
  • border: borde de la caja
  • margin: espacio externo (entre cajas)

Propiedades de organizacion

  • display: flex: coloca divs en fila o columna
  • gap: separacion entre contenedores
  • background-color: color de fondo
  • border-radius: esquinas redondeadas
div-columnas.html 
<style>
  .contenedor {
    display: flex;
    gap: 16px;
  }
  .columna {
    flex: 1;
    background-color: #e8eaf6;
    padding: 20px;
    border-radius: 8px;
  }
</style>

<div class="contenedor">
  <div class="columna">Columna 1</div>
  <div class="columna">Columna 2</div>
  <div class="columna">Columna 3</div>
</div>

Estructura completa de una pagina con div

Combinando contenedores se construye el esqueleto visual completo de un sitio: encabezado con navegacion, cuerpo con secciones y pie de pagina.

div.header (logo + nav)
↓
div.contenido (secciones principales)
↓
div.footer (creditos y contacto)
estructura-pagina.html 
<div class="header">
  <h1>Nombre del Sitio</h1>
  <nav> ... </nav>
</div>

<div class="contenido">
  <div class="seccion" id="inicio">
    <h2>Inicio</h2>
    <p>Contenido de la seccion.</p>
  </div>
</div>

<div class="footer">
  <p>Derechos reservados 2025.</p>
</div>

Paso a paso: estructura tu pagina con contenedores

1

Define los bloques principales

Identifica tres zonas: encabezado, contenido y pie de pagina.

2

Crea un div para cada zona

Asigna a cada uno una class descriptiva: header, contenido, footer.

3

Agrega secciones internas

Dentro de contenido, crea varios <div class="seccion"> con un id unico que coincida con los enlaces de tu barra de navegacion.

4

Aplica estilos en el head

Da color de fondo, padding y margin a cada bloque para diferenciarlos visualmente.

5

Prueba la navegacion interna

Haz clic en los enlaces de tu barra y verifica que la pagina se desplace a la seccion correspondiente.

Insercion de Mapas desde la Web

Integracion de mapas interactivos mediante iframe

Insertar un mapa interactivo permite ubicar geograficamente un negocio, una institucion o un evento dentro de un sitio web. Se logra mediante la etiqueta <iframe>, que incrusta contenido externo (como Google Maps) dentro de nuestra pagina.

Que es un iframe

La etiqueta <iframe> (inline frame o marco en linea) permite incrustar una pagina web o un recurso externo dentro de otra pagina. Es el mecanismo estandar para insertar mapas, videos de YouTube y otros contenidos de terceros.

Como obtener el codigo de un mapa de Google Maps

Google Maps ofrece un codigo de insercion listo para copiar. No requiere cuenta ni clave de programador para el uso basico de incrustacion.

1

Abre Google Maps

Ingresa a maps.google.com y busca la ubicacion que deseas mostrar (tu universidad, un evento, un lugar de interes).

2

Haz clic en "Compartir"

En el panel de la ubicacion, localiza y presiona el boton Compartir.

3

Selecciona "Insertar un mapa"

En la ventana emergente, cambia de la pestana "Enviar un vinculo" a la pestana Insertar un mapa.

4

Copia el codigo HTML

Google mostrara un codigo <iframe> completo. Presiona Copiar HTML.

5

Pega el codigo en tu archivo

Coloca ese <iframe> dentro de la seccion de tu pagina donde quieras que aparezca el mapa.

Estructura del codigo de un mapa embebido

El codigo que proporciona Google tiene esta estructura. Puedes ajustar width, height y style segun el diseno de tu sitio.

mapa-embebido.html 
<iframe
  src="https://www.google.com/maps/embed?pb=..."
  width="600"
  height="450"
  style="border:0; border-radius:10px;"
  allowfullscreen
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade">
</iframe>
⚠
El valor de src que empieza con ?pb= es una cadena larga y unica generada por Google para cada ubicacion. No la escribas manualmente: siempre copiala directamente desde la opcion "Insertar un mapa" de Google Maps.

Buenas practicas al insertar mapas

Diseno responsivo

Para que el mapa se adapte a pantallas moviles, usa width: 100% en lugar de un ancho fijo en pixeles, y envuelvelo en un contenedor <div>.

Rendimiento

Agrega loading="lazy" para que el mapa no ralentice la carga inicial de la pagina. Se cargara cuando el usuario se acerque a el.

Contexto para el usuario

Acompana siempre el mapa con texto: la direccion escrita, referencias cercanas o instrucciones de acceso. El mapa complementa, no sustituye la informacion.

Coherencia visual

Aplica border-radius y, si corresponde, un borde que combine con la identidad visual de tu sitio para que el mapa se integre al diseno.

Sitio Web Visual de una Pagina

Disenaras, construiras y publicaras en linea un sitio web visual de una sola pagina sobre un tema academico de tu eleccion, integrando los tres temas de la unidad: una barra de navegacion funcional, una estructura de contenido organizada con contenedores y un mapa embebido que ubique el proyecto en el mundo real.

Herramienta: Bloc de Notas + GitHub Formato: Sitio web publicado (GitHub Pages) Trabajo: Individual o equipos de 2 Nivel: Licenciatura
P
Planteamiento del Problema

Como estudiante de Diseno Grafico, necesitas presentar un tema academico o cultural de manera profesional en un sitio web navegable, bien estructurado y con orientacion geografica. El sitio debe permitir al usuario moverse con facilidad entre secciones, comprender la jerarquia del contenido y ubicar fisicamente el tema tratado (una sede, un evento, un lugar de interes).

Temas sugeridos (el alumno elige uno aplicable a su vida universitaria):

  • Promocion de un evento academico o cultural de tu facultad
  • Guia visual de un museo, galeria o espacio de diseno de tu ciudad
  • Mini portafolio personal con seccion de ubicacion de contacto
  • Sitio informativo sobre un movimiento de diseno y un lugar historico asociado
  • Presentacion de un proyecto o taller estudiantil con su sede
1
Investigacion y Boceto 20 min

Antes de escribir codigo, planifica la arquitectura de tu sitio:

  • Selecciona el tema y redacta el titulo principal del sitio.
  • Define las secciones de tu pagina (minimo 4): por ejemplo Inicio, Acerca de, Galeria, Ubicacion.
  • Dibuja un boceto en papel de la distribucion: donde ira la barra de navegacion, el contenido y el pie.
  • Elige una paleta cromatica en formato hexadecimal coherente con el tema.
  • Identifica la ubicacion geografica que insertaras con el mapa.
2
Construccion de la Barra de Navegacion 25 min

Retoma tu archivo ejercicio-integral.html o inicia uno nuevo integrando lo aprendido en el Tema 1:

  • Construye una barra con <nav>, <ul>, <li> y <a>, con minimo 4 enlaces hacia anclas internas.
  • Aplica estilos CSS: list-style: none, display: flex, color de fondo, padding y efecto :hover.
  • Marca el enlace activo con una clase distintiva.
  • Opcional avanzado: haz la barra fija con position: sticky para que permanezca visible al desplazarse.
3
Estructura del Contenido con DIV 40 min

Organiza todo el sitio con contenedores, aplicando lo aprendido en el Tema 2:

  • Envuelve la navegacion en un <div class="header"> junto al titulo principal.
  • Crea un <div class="contenido"> con minimo 4 secciones internas (<div class="seccion" id="...">), cuyos id coincidan con los enlaces de la barra.
  • Cada seccion debe incluir un encabezado (<h2>), texto (<p>) y al menos una imagen relevante.
  • Cierra con un <div class="footer"> con tu nombre, carrera, grupo y anio.
  • Aplica el modelo de caja (padding, margin, border-radius) y colores de fondo para dar identidad visual a cada bloque.
4
Insercion del Mapa 15 min

Integra la ubicacion geografica siguiendo el Tema 3:

  • Obten el codigo <iframe> desde "Insertar un mapa" en Google Maps u OpenStreetMap.
  • Insertalo dentro de tu seccion de Ubicacion o Contacto.
  • Aplica width: 100%, border-radius y loading="lazy".
  • Acompana el mapa con la direccion escrita y una referencia de acceso.
5
Publicacion en GitHub Pages 15 min

Pon tu sitio en vivo con una URL publica:

  • Crea un repositorio publico en GitHub (ej. sitio-web-[tu-apellido]).
  • Sube tu archivo nombrandolo index.html.
  • Activa GitHub Pages desde Settings > Pages, seleccionando la rama principal.
  • Verifica que el sitio, la navegacion y el mapa funcionen desde la URL publica en otro dispositivo.
6
Reflexion Critica y Construccion Colaborativa 20 min

Intercambia tu URL publicada con un companero de clase y completen lo siguiente:

  • Navega el sitio de tu companero y evalua: es facil orientarse con la barra? La estructura es clara? El mapa aporta valor?
  • Redacta una retroalimentacion constructiva de al menos tres observaciones.
  • En tu propio sitio, agrega una seccion final con un parrafo de reflexion: que decisiones de jerarquia visual y navegacion tomaste, que dificultad tecnica enfrentaste y como la resolviste, y de que manera este sitio podria aplicarse de forma real en tu contexto universitario.
